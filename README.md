# -NES_Dendy_STM32
Эмулятор легендарных игр на STM32 с дисплеем!

## Пробный запуск InfoNES

Откройте `STM32F407_NES_Dendy` в VS Code и соберите пресет `debug`.
Для прошивки STM32 используйте `build/debug/STM32F407_NES_Dendy.hex`.

На SD-карте в картридере платы (FatFs, том `0:`) разместите:

- `NES/InfoNES.bin` из `build/debug/NES/InfoNES.bin`.
- `game/<имя>.nes` — один распакованный образ с маппером 0 (NROM).

После перезапуска плата считывает модуль и ROM в память и запускает игру
автоматически. Модуль `InfoNES.bin` содержит исполняемый код STM32. Используйте
файл, полученный из сборки проекта. Для замены игры или модуля скопируйте
новый файл и перезапустите плату.

Клавиатура подключается через вкладку «Управление NES» в SdCardBrowser и
физический UART платы. Пробная версия выводит изображение на ILI9341 и
использует тайминг NTSC. Звук, меню и тайминги Dendy будут добавлены отдельно.

При диагностике JSON-команда `nesstat` возвращает текущее состояние запуска
(`running`, `sd_unavailable`, `game_missing`, `multiple_games`,
`game_invalid`, `module_missing` или `module_invalid`). Ответ также содержит
`fps_x10`, `frame_ms_x10` и счётчик ошибок DMA дисплея `lcd_dma_errors`.
