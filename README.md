# -NES_Dendy_STM32
Эмулятор легендарных игр на STM32 с дисплеем!

## Пробный запуск InfoNES

Откройте `STM32F407_NES_Dendy` в VS Code и соберите пресет `debug`.
Для прошивки STM32 используйте `build/debug/STM32F407_NES_Dendy.hex`.

На SD-карте в картридере платы (FatFs, том `0:`) разместите:

- Содержимое `build/debug/NES` в папку `NES` на SD-карте.
- Распакованные образы `.nes` в папку `game` или её подпапки.

Прошивка автоматически выбирает один из модулей для мапперов 0 (NROM),
1 (MMC1), 2 (UxROM), 3 (CNROM), 4 (MMC3) или 7 (AxROM) по заголовку
iNES или NES 2.0. Для каждой новой игры достаточно скопировать `.nes`.
Поддерживаются стандартные платы. У MMC3 прерывания привязаны к событиям
строки, поэтому игры с чувствительным таймингом могут отличаться от оригинала.
MMC6 и MC-ACC, а также платы с переключаемой PRG RAM свыше 8 КиБ не поддерживаются.

У MMC1 и MMC3 с батарейкой сохранение пишется рядом с образом при выходе
через кнопку «В меню». Например, `Zelda.nes.sav`.

Подключитесь по физическому UART в SdCardBrowser, откройте «Управление NES»
и включите управление. На этой плате COM5 отвечает при 460800 бод.

- **Browser** показывает папки и файлы SD-карты. A / Start открывает папку.
  B поднимается на уровень выше, а из корня возвращает на экран выбора режима.
- **Games** показывает образы `.nes` и папки в `/game`. A / Start запускает образ
  или открывает папку. B поднимается на уровень выше, а из `/game` возвращает
  на экран выбора режима.
- В обоих режимах стрелки вверх и вниз перемещают выделение. По умолчанию
  A — X, Start — Enter, B — Z.

InfoNES выводит изображение на ILI9341 и выбирает тайминг NTSC, PAL или Dendy по заголовку образа.

При диагностике JSON-команда `nesstat` возвращает текущее состояние запуска
(`waiting`, `running`,
`game_invalid`, `mapper_unsupported`, `module_missing`, `uxrom_module_missing`, `axrom_module_missing`, `mmc1_module_missing`, `cnrom_module_missing`, `mmc3_module_missing`, `module_invalid`, `game_read_error`, `save_read_error` или `save_write_error`). Ответ также содержит
`fps_x10`, `frame_ms_x10` и счётчик ошибок DMA дисплея `lcd_dma_errors`.
